# ⚡ boily

> The all-in-one interactive fullstack project generator CLI for turbo monorepos

---

## What is this?

**boily** is a modern, opinionated CLI tool for bootstrapping and managing fullstack projects **inside a turbo monorepo**.

- **Select your stack** — React, Next.js, Fullstack, and more
- **Add powerful extras** — Tailwind, Prisma, tRPC, Eslint, and more
- **Generate boilerplate** using official generators or curated templates
- **Auto-install and configure** your favorite tools
- **Everything organized in a turbo monorepo** with best practices, fast

---

## Why boily?

> **Unified experience:** One CLI, many stacks and add-ons
>
> **Zero guesswork:** Interactive prompts guide you through setup
>
> **Instant productivity:** Get a ready-to-code turbo monorepo in minutes
>
> **Customizable:** Choose only the features you want
>
> **Modern tech:** Built for Vite, Next.js, Express, Tailwind, Prisma, and more
